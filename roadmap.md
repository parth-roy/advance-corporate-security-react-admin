# ACS Admin Panel Roadmap

- [x] Design system tokens, typography (Manrope), semantic badge variants, and shared utilities
- [x] Shared types, realistic ACS demo dataset, and SSR-safe localStorage context store
- [x] Layout shell: collapsible sidebar, top header with breadcrumbs, global search, notifications, and profile
- [x] Module 1: Dashboard overview (6 KPI cards, attendance chart, recent recruitment, activity timeline, quick actions)
- [x] Module 2: Recruitment panel (KPIs, table, filters, detail drawer, candidate add/edit/delete form)
- [x] Module 3: Uniform Management panel (KPIs, inventory table, add/stock/issue/return dialogs, issue & stock history)
- [x] Module 4: Attendance panel (KPIs, daily table, mark/edit/bulk dialogs, CSV export, monthly calendar)
- [x] Module 5: ESI & PF Management panel (KPIs, contribution table, filters, CSV export, detail drawer)
- [x] Module 6: Salary Generation panel (KPIs, filters, salary table, edit modal, details drawer, process/export)
- [x] Module 7: Payslips panel (KPIs, table, regenerate, PDF download, corporate payslip preview)
- [x] Module 8: Billing panel (KPIs, table, create/edit/mark-paid, export, corporate invoice preview)
- [x] Module 9: Settings & Profile (admin profile, company info, logo, contact info, basic preferences)
- [x] Verification: tests, build log check, and Playwright end-to-end visual check
